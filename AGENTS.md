# Working on this repository

- Each guide is one file: a principle, then entries under stable anchors (`## mean-forecasts`), then references and
  versions. The README says what an entry holds.
- An anchor never changes meaning and is never removed: a withdrawn default stays, marked withdrawn, with the reason.
- A changed default is a new version of its guide, listed under *Versions* at its end.
- Every default rests on an argument and on references a reader can check (DOI, or a stable URL). Never add a
  reference you have not checked exists and says what the entry cites it for. A precedent is not a reason.
- Text is written for LLM readers as much as for people: plain, explicit, one meaning per term.

## Pull requests

- Keep the description short: a bulleted list of what was done, each item one or two sentences. No other sections.
- Pull requests are reviewed and merged by a maintainer, never by the author's agent.
